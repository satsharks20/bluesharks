The format

  • SECTION: READING_WRITING (English) or SECTION: MATH once at the top.
  • Three modules, each between its line and END MODULE: MODULE 1, MODULE 2 EASY, MODULE 2 HARD (EASIER / HARDER also work). Students who get at least the routing threshold of Module 1 right (65%) get the hard Module 2.
  • Questions are numbered from QUESTION 1 in every module, with no gaps, and end with END QUESTION.
  • Fields in this order: CATEGORY, SKILL, DIFFICULTY, TYPE (optional), PASSAGE (optional), PROMPT, A–D, ANSWER, EXPLANATION. A value can run over several lines.
  • An official module has 27 English or 22 Math questions. Other sizes are allowed but are flagged, and scaled scores need official sizes.

Math formulas

Plain text works, as in the other LUE SAT site's PDFs: x^2, 3/14, 25π, $90. On upload a power becomes a superscript (x^2 → x², (2)^t → (2)ᵗ) and $ stays a dollar sign. For fractions, roots and other formulas that should look like the real test, use LaTeX instead.

LaTeX: write every formula in LaTeX between dollar signs, the same way as the rest of the question bank: $3x + 7 = 22$, $x^2$, $\frac{3}{4}$, $\sqrt{2}$, $\pi r^2$, $x \le 5$. A formula on its own line goes between double dollar signs: $$y = 2x + 1$$. A dollar amount is written inside a formula as $\$78$. A file is read as LaTeX as soon as it uses a LaTeX command (\frac, \$, …) or a formula like $x$; then a lone $ is rejected, and so is a formula that cannot be displayed; the upload lists each one. Do not mix the two styles in one file. After uploading, every question can be checked in a preview exactly as students see it, and the editor has a visual equation editor.

Paragraphs and text

Lines that wrap are joined back together. To start a new paragraph (for example "Text 1" and "Text 2", or a new line in a Math question), leave a blank line. Start a bullet with • or -. In English, ______ is a blank, **bold**, *italic* and __underline__ work; underlining done with the word processor is lost in a PDF, so use __underline__.

Graphs, tables and images

A PDF cannot carry a figure into a question. After publishing, open the question from the test page and drag the image into the editor.

Scanned PDFs and photos do not work: the text must be selectable.
